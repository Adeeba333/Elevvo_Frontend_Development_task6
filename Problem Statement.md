# Problem Statement #
Develop a responsive, multi-page freelance client dashboard using React.js, React Router, Recharts, and Tailwind CSS. 
The dashboard should include essential pages such as Overview, Projects, and Profile Settings to display project statistics, track earnings, manage project information, and update profile details. 
A consistent sidebar and top header should provide seamless navigation across pages. 
React Router should enable page transitions without refreshing, while Recharts should visualize monthly earnings and task distributions. 
Responsive design techniques should ensure a consistent layout across desktop, tablet, and mobile devices. 
Additional interactive features, such as dark/light theme switching and a notification dropdown, can improve the overall user experience.


# Technical Problem Review #
- Designed a responsive multi-page dashboard layout with a consistent sidebar and top header.
- Used reusable React components to organize dashboard sections and maintain consistent UI elements.
- Implemented React Router for seamless navigation between dashboard pages without page reloads.
- Created summary cards to display project statistics, earnings, and tasks due.
- Integrated Recharts to visualize monthly earnings and task distributions.
- Used structured mock data to display project details, deadlines, statuses, and recent activities.
- Implemented conditional rendering and status filtering to manage project information dynamically.
- Used React Context API and localStorage to manage and preserve dark/light theme preferences.
- Added an interactive notification dropdown displaying the three most recent activities.
- Applied responsive design techniques to adapt dashboard components across desktop, tablet, and mobile screens.
- Implemented interactive UI elements, including a collapsible mobile sidebar and a scroll-to-top button.
